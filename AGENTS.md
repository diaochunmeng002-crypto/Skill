# Repository Instructions

- Store each Codex skill at `skills/<skill-name>/SKILL.md`.
- Use lowercase letters, digits, and hyphens for skill directory names.
- Create `scripts/`, `references/`, or `assets/` only when the skill needs them.
- Validate every new or substantially changed skill with the installed
  `skill-creator` validator before committing.
- Preserve independent skill scope; do not share mutable state between skills
  unless a documented workflow requires it.
